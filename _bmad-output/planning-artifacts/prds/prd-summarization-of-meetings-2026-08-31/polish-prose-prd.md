# Редактура формулировок PRD

Этот документ существует, чтобы помочь архитектору и авторам историй однозначно понять продуктовое обещание, границы MVP, критерии выпуска и проверяемые требования локального приложения для суммаризации встреч.

- **Читатели:** люди; архитекторы, PM и авторы историй.
- **Структурная основа:** Strategic/Context (Pyramid). Текущий PRD перечитан после применения части безопасных рекомендаций из `polish-structure-prd.md`; структурные решения повторно не оцениваются.
- **Стиль:** Microsoft Writing Style Guide.
- **Исходный объём:** **4 369 слов** по текущему запуску `word_metrics.py`.
- **Стиль, тон и голос:** формальный русскоязычный PRD с прямыми нормативными формулировками, стабильными FR/NFR/SM-ID и намеренно капитализированными терминами Глоссария. Сохранены технические сокращения, числовые пороги и проверяемая схема «требование → последствия». Предлагаются только минимальные правки, устраняющие неоднозначность, грамматические сбои, кальки и неясных субъектов действия.
- **Ограничение:** содержание считается утверждённым; `prd.md` не изменён.

Итого: **30 рекомендаций**. Они не дают сокращения: при принятии всех конкретных замен текст вырастет ориентировочно на **~50 слов** — около **1,1%** от текущих 4 369 слов, главным образом потому, что в неоднозначных местах появляются явные субъекты и логические связи. Лимит длины не задан; ни одно утверждённое требование, значение порога или читательская опора не удаляются. Рекомендация с FR-1 намеренно оставлена вопросом: она требует выбрать уже утверждённую логику ограничения, а не придумывать её редактору.
